# Weather App

A responsive Weather App built using HTML, CSS, and JavaScript. It uses the OpenWeatherMap API to fetch and display real-time weather information for any city.

## Features
- Search weather by city name
- Displays current temperature
- Shows weather condition and icon
- Displays humidity and wind speed
- User-friendly and responsive interface
- Handles invalid city names with error messages

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- OpenWeatherMap API

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Add your OpenWeatherMap API key in the JavaScript file.
4. Open `index.html` in your browser.
